# Fontes do arquivo final

Instâncias estáticas (TTF) das fontes que as peças usam, para rasterizar o arquivo final sem navegador
(`packages/render/src/rasterizar.mjs`). A prévia no navegador usa as mesmas famílias pelo Google Fonts.

| Arquivo | Família | Instância |
|---|---|---|
| `BodoniModa-Regular.ttf` | Bodoni Moda | tamanho óptico 28, peso 400 |
| `BodoniModa-Italic.ttf` | Bodoni Moda | tamanho óptico 28, peso 400, itálico |
| `BodoniModa-SemiBold.ttf` | Bodoni Moda | tamanho óptico 28, peso 600 |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono | peso 400 |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono | peso 500 |

Origem: API do Google Fonts (css2, instâncias estáticas), baixadas em 02/11/2026.
Licença: SIL Open Font License 1.1 (`OFL-BodoniModa.txt`, `OFL-IBMPlexMono.txt`). A OFL permite embutir
e distribuir as fontes com o software; não permite vendê-las sozinhas.
